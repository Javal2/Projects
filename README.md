## Working with the source

The folders contain frontend website assets and source files. For static projects, open the relevant `index.html` through a local HTTP server. Tiffin World includes separate `website`, `customer`, `vendor`, and `admin` sections.

> **Preview note:** GitHub Pages can serve static HTML, CSS, JavaScript and assets. It cannot operate server-side functionality such as PHP / Node.js backends, databases, authentication, payments or form delivery on its own.
