# Projects

A collection of static website projects and landing pages assembled in a single portfolio repository.

This repository contains multiple standalone sites, each with its own folder, assets, and page structure. Most projects are plain HTML/CSS/JavaScript and can be opened directly in a browser without a build step.

## Included projects

- BongWholesale
- BulkPharmaChem
- Finchbyte
- Flemming Pharma
- Tiffin World
- United Metal
- Fortis Dental
- Vise Organic

## How to use this repo

1. Open any project folder.
2. Open the main page such as `index.html`.
3. Preview it in a browser to view the website.

## Notes

- Each project keeps its original folder structure and relative asset paths.
- This repository is intended for portfolio/archive viewing and local preview.
- Some projects may contain additional admin/vendor/customer sections or mock data files.
